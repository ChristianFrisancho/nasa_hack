# Proyecto: recomendación de cultivos para Piura (Perú)

Sistema que, dado un campo en Piura (ubicación, suelo, pendiente, profundidad, agua, presupuesto del agricultor y cultivos que le interesan), recomienda el siguiente cultivo.

Carpetas (una por bot):
- cultivos/       qué se cultiva en Piura, plagas, requerimientos de cada cultivo
- suelos/         tipos de suelo, bases de datos de suelo, pendiente, profundidad, ubicación y características del campo
- restricciones/  presupuesto del agricultor, restricciones del campo y del modelo
- modelo/         datos más determinantes, pruebas, esquema del modelo
- consolidado/    síntesis del coordinador (Grok Bot)

Reglas: cita fuente (URL) por dato, marca nivel de confianza, CSV en UTF-8, y deja un PROGRESO.md en tu carpeta actualizado tras cada ronda.
